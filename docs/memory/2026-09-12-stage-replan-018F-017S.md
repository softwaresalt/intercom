(full `go test ./...` GREEN after **every** task) are **jointly unsatisfiable for any shipment
with more than one test-bearing task**. Revisions 10–15 — surface predicates, harness-state

so leftover queued tasks under `018-F` would be re-harnessed and re-create the deadlock. Task
disposition was therefore **load-bearing, not cosmetic**.
