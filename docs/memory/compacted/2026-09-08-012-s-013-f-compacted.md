## Durable Learnings

- The repo's own `classify_shipment_close_path()` classifier
  (`.copilot/installed-plugins/autoharness/autoharness/src/autoharness/gates/shipment_closure.py`)
  is directly invokable via `python -c` for a fast, authoritative CASCADE-vs-safe-close
  verdict — avoid hand-deriving the fully-covered-root check when this tool is present.
- GitHub REST reply-to-review-comment requires the PR-scoped path
  (`/repos/{owner}/{repo}/pulls/{pr_number}/comments/{id}/replies`); the bare
  `/repos/{owner}/{repo}/pulls/comments/{id}/replies` 404s even though the
  comment itself resolves fine via `GET pulls/comments/{id}`. Full record:
  `docs/compound/2026-09-08-pr-review-comment-reply-rest-endpoint-requires-pr-number.md`.
- A review finding that duplicates an already-deferred cluster's *topic* is not
  automatically re-deferrable if it surfaces later as a **live, PR-scoped**
  finding on the shipment's own diff (same Usage-block text this shipment
  already edits) — classify at the point raised; same-contract-surface
  completions win over "already bundled elsewhere" reasoning.
