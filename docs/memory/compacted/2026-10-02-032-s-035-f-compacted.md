  for an absent file alike, and its stderr is locale-dependent. The two cases are
  instead told apart with structured queries (`rev-parse`, `ls-tree -z`). An absent
  file was NOT made an error.

  gpt-5.6-sol (anchor), claude-opus-5.5 and gemini-3.8-flash.**

  * Round 3 (`0540220`): READY × 3.
