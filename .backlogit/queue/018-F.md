CURRENT CONTRACT - THE WHOLE OF IT:
Close the PROHIBITION half of the Stage default-branch policy gap (historical evidence: commit fdff9e4). After this release unit:
1. Stage is forbidden, in operative policy and in its own agent contract, from committing or pushing artifacts on the default branch.
2. Stage is granted, in the same surfaces, the authority to create and check out a dedicated artifact branch chore/stage-{scope-slug}.
3. A NON-NEGOTIABLE Step 1.9 gate in _stage.agent.md requires that branch to exist BEFORE any tracked Stage artifact mutation, under a CATEGORICAL deferral rule.
4. The Orchestrator/operator - never Stage - pushes the branch and opens/merges the staging PR. That prohibition is unweakened.

EXECUTABLE SET: exactly ONE task, 018.008-T (size M). Shipment 017-S = [018-F, 018.008-T].

SINGLE-TASK LIFECYCLE - THE REASON THE HARNESS MACHINERY IS GONE: P-004 requires EVERY generated test function to be red before implementation; Ship Step 4.3 requires the FULL "go test ./..." to be green after EVERY task. With two or more test-bearing tasks in one shipment those two rules are jointly unsatisfiable - task 1 going green still leaves the others red, Step 4.3 fails, and no task can complete. Revs 10-15 tried to bridge that with surface predicates, then a harness-state manifest, a terminal witness, a selector flag and an MP0-MP6 mutation-proof series, and failed review each time. The re-plan removes the CAUSE instead: ONE queued task under 018-F means ONE red function, one red-to-green transition, and a green full suite immediately. NO manifest, witness, selector, surface predicate, or MP-series check is required or permitted in this release unit. Adding a second queued task under 018-F re-creates the deadlock and is FORBIDDEN.

DEFERRED TO 019-F / 018-S (NOT in this release unit): handback record emission, stage_artifact_paths derivation, no-shipment terminal reachability, the Stage artifact commit step, out-of-root path safety, the Orchestrator Step 1.5 branch-discovery and post-merge verification arms, the generalized structure-aware direct-push detector, the fixture corpus and harness-state manifest, regeneration-resistant CI wiring, CODEOWNERS/ledger updates, and the mutation proofs. 019-F's tasks carry blocking dependencies on 018.008-T.

INTERIM RESIDUAL RISK (accepted, explicit): until 019-F lands, Stage has no automated persistence route - it creates the branch and commits, and the operator or Orchestrator pushes and opens the PR manually. That is exactly the interim behaviour in use today and is strictly safer than the gap this unit closes. No mechanical CI enforcement exists until 019.005-T, so the corrected contract is regeneration-vulnerable in the interim; this is a KNOWN and ACCEPTED limitation of the reduced unit, tracked by 019-F.
