READINESS GATE - NOT A DELIVERY FEATURE.

PURPOSE. This feature exists solely to hold the single readiness-decision item (021.001-T) whose unresolved state mechanically suppresses every deferred Stage-enforcement shipment. Its shipment 020-S is a LOCK TOKEN, never executed and never claimed. 018-S and 019-S each carry a blocks dependency edge to 020-S, and backlogit requires both endpoints of a shipment blocks edge to be shipments, which is why the lock token is modelled as a shipment rather than as a bare task.

NEVER EXECUTED. 020-S is status BLOCKED, so Orchestrator Step 2 (which triggers on QUEUED shipments only) never selects it, and Ship Step 0.5 item 1b rejects it if it is ever routed. 021.001-T is resolved by STAGE through deliberation and plan review, not by Ship through a build loop. There is no code, no test and no harness in this feature.

UNLOCK PROCEDURE. Stage removes the lock only after 021.001-T records a REVIEWED decision: backlogit dep remove 018-S 020-S and/or backlogit dep remove 019-S 020-S, then restructure and re-queue that shipment, then run impl-plan, plan-harden and plan-review on the resulting plan. Removing an edge without the review is a P-006 violation. Ship and the Orchestrator MUST NOT remove these edges.
