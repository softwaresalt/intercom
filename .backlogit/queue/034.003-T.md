U4-T1b-2. Implement D-2 of the spike findings EXACTLY AS SPECIFIED -- this task exercises NO design discretion. The allowance is keyed on the CALL'S ACCESS MODE, never on the file. A call is ALLOWED only when ALL FOUR conditions hold: (1) the selector is exactly syscall.CreateFile; (2) the extracted extent is a real call with a BALANCED argument list; (3) after discarding a trailing-comma artifact the list has EXACTLY 7 arguments, the Win32 CreateFileW arity -- any other arity is undecidable and REJECTED; (4) arg index 1, dwDesiredAccess, is the LITERAL 0. Everything else is REJECTED: a non-call reference, an unbalanced extent, a wrong arity, and any non-zero access expression including a parenthesised or symbolic one such as uint32(syscall.GENERIC_WRITE). The predicate must never widen the gate; its only failure direction is a false positive. If the implementation cannot follow D-2, HALT and return to Stage rather than re-deciding (P-010). Size: S | Complexity: medium.
