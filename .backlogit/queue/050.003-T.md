U3 of plan docs/plans/2026-10-07-intercom-go-retiredarch-correctness-plan.md (stash 990AFA71). Add containedRegularFile(root, rel string) (ok bool, reason string) to tools/gatecheck/internal/retiredarch/retiredarch.go: split rel on '/', reject empty/'.'/'..' components (and on Windows components containing '\' or ':'); os.Lstat each intermediate prefix (must be IsDir with no ModeSymlink|ModeIrregular) and the final component (must be Mode().IsRegular()); an Lstat error satisfying errors.Is(err, fs.ErrNotExist) returns ok=true so a deleted file keeps the existing scanPath read-error text; ANY OTHER Lstat error (permission, I/O) returns ok=false with reason 'lstat <prefix>: <err>' (fail-closed per D-RA-2; amended per PR #109 review). In runRepoScan, when !ok append '%s: not a contained regular file: %s (fail-closed synthetic finding)' and skip scanPath. Stdlib only; no filepath.Abs/EvalSymlinks (INV-5). Independent of other units.
