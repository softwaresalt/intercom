009-F U5. EXISTS BECAUSE ADVERSARIAL REVIEW FOUND A BLOCKER. Wrap(kind, cause) (apperr.go:142) takes NO message parameter and derives msg from cause.Error(); New(kind,msg) DROPS the cause. So no current constructor can both preserve the cause (for errors.Is(err, os.ErrNotExist)) and retain human-readable context — which 010-F U1 requires and TestNewRootOnMissingDirReturnsPathViolation asserts. Add func Wrapf(kind Kind, cause error, format string, args ...any) *Error. AC: cause reachable via Unwrap; errors.Is against the Kind sentinel still matches; Wrapf registered in printf.funcs alongside Newf; nil-cause guarded; Wrap/New unchanged.
