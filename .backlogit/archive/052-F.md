Close two integrity gaps in the merge-blocking write-path gate (stash B83F53BB, 05E12A6F): (1) writepath.DefaultGitRunner runs git ls-files without -z, so a tracked internal/** or cmd/** Go file whose path git C-quotes (non-ASCII, quote, backslash, control character) is silently never scanned (false-clean), and it inherits ambient GIT_* environment (a GIT_INDEX_FILE partial index yields a non-empty partial listing that ED-7 does not catch); (2) the fixture self-test (runFixtureSelfTest) reads scripts/testdata/writepath fixtures through links with no Lstat containment. Fix: NUL-delimited -z selection with a strict parse and selected-path rules, an in-package copy of gitRunnerEnv (D7BF9F74 shape), and reuse of the existing containedRegularFile for fixtures; one authorized adaptation of the header-frozen oracle decode; one stale retiredarch comment.
