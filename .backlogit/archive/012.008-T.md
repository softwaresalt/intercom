Fix 5158769F. tests/integration/output_path_guard_test.go's createDirectorySymlink (lines 78-89) calls t.Skipf on ANY os.Symlink error, so symlink-containment subtests can silently skip for any reason and mask a real regression - unlike internal/pathsafe's requireSymlinkOrFailClosed which fails closed except for one enumerated privilege case. Add build-tagged windows and non-windows privilege predicates to tests/integration mirroring internal/pathsafe's isSymlinkPrivilegeError (ERROR_PRIVILEGE_NOT_HELD = 1314), then rewrite createDirectorySymlink. EXPLICIT PER-PLATFORM BEHAVIOR: on WINDOWS, t.Skipf ONLY on 1314 and t.Fatalf on every other error; on NON-WINDOWS, PRESERVE the existing UNCONDITIONAL skip exactly as internal/pathsafe's requireSymlinkOrFailClosed does. Do NOT make non-Windows failures fatal - that would change behavior on the only REQUIRED CI job (ubuntu). DUPLICATION RATIONALE to record in the helper comment: isSymlinkPrivilegeError is not merely unexported, it is defined in _test.go files (symlink_privilege_windows_test.go, symlink_privilege_other_test.go) and is therefore unimportable even if exported; a shared internal/testsupport package was rejected as disproportionate for two call sites, and the drift risk is noted. Domain: tests.
