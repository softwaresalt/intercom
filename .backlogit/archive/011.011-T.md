Resolves 707FE72B. scripts/lib/OutputPathGuard.ps1:118 builds repoRootWithSep = resolvedRepoRoot + DirectorySeparatorChar unconditionally. Traced: Normalize-GuardPath trims trailing separators only when fullPath.Length -gt pathRoot.Length, so 'C:\' and '/' keep theirs, yielding a doubled separator at line 118 - StartsWith never matches and a legitimate in-root path is FALSELY REJECTED. CRITICAL SAFETY REQUIREMENT: two reviewers independently found that 'existing suite passes unchanged' is inadequate - the existing suite has NO sibling-prefix case, and the separator suffix is the SOLE mechanism preventing a sibling from matching, so the two most natural fixes convert a fail-safe over-rejection into a GENUINE CONTAINMENT BYPASS the existing suite passes cleanly. Approach: test-first, red phase mandatory. Width: PowerShell + tests. AC1 MANDATORY NEGATIVE TEST - a sibling-prefix candidate (root plus '-evil') is REJECTED, exercised at a DEEPLY NESTED root and at a TOP-LEVEL DIRECTORY root (e.g. root C:\repo vs candidate C:\repo-evil). NOT at a drive root: with root 'C:\' the candidate 'C:\-evil' is a legitimate DESCENDANT and must be ACCEPTED; the only way to make it reject is to reinstate the very bug this unit fixes. The sibling-prefix hazard class exists only for non-root roots. AC2 positive regression - a legitimate in-root path at a drive root (C:\) and at a POSIX root (/) is accepted; both fail before and pass after; these roots get the POSITIVE case only. AC3 the test helper must DECOUPLE GuardPath from RepoRoot before the root-level fixtures can exist - today runOutputPathGuard derives the guard path from the root, which would require placing the script at the filesystem root (privileged). AC4 UNC is EXCLUDED from the failing-fixture requirement: GetPathRoot on a UNC path excludes the trailing separator so it is already trimmed and produces a correct single separator; a UNC fixture would pass BEFORE the fix, violating fail-before/pass-after, and a real UNC share is not creatable on hosted CI. AC5 '..'-style escapes and all existing rejection behaviour preserved; the full existing guard suite passes.
